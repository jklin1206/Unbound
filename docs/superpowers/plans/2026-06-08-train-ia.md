# Train Tab + My Workouts IA — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restructure the `Program` tab into a `Train` tab with three peer sub-tabs (Today's Plan · My Workouts · Routines), add a one-tap Quick Log path, and move the rank library to a compact card on Home — so logging your own workout is ≤3 taps without adding new features.

**Architecture:** Almost entirely re-org of existing screens. The only net-new code is: the `.myWorkouts` sub-tab enum case, a `MyWorkoutsView` landing that composes existing entry points, a `QuickLogDraftFactory` (empty `TrainingSessionDraft` → existing `ActiveWorkoutContainerView`), and a `HomeRanksCard` that presents the existing `ProgramRankLibraryView`. Quick Log reuses the active session's existing `appendCustomExercise` / `addSet` machinery.

**Tech Stack:** Swift / SwiftUI, XcodeGen (`project.yml` → `.xcodeproj`), XCTest, iOS Simulator (iPhone 17, iOS 26.3, udid `810087B3-226D-4398-8ABD-9FF61E642E1D`), bundle `com.unboundapp.ios`, scheme `UNBOUND`.
